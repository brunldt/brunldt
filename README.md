### About Me <img src="https://play.pokemonshowdown.com/sprites/ani/haunter.gif" height="40" alt="Haunter" valign="middle" />

Full Stack Developer with 2+ years of experience building and maintaining production systems end to end, from database design to deployed infrastructure.

My work spans backend development in **PHP** and **Node.js (NestJS)**, building and consuming RESTful APIs, frontend development, and contributing to technical and architectural decisions. I've also worked on migrating legacy systems to **AWS EC2**, cutting infrastructure costs and improving reliability in the process.

**Currently focused on** <img src="https://play.pokemonshowdown.com/sprites/ani/yveltal.gif" height="64" alt="Yveltal" valign="middle" />
- Distributed systems concepts, including Kafka and event-driven architectures
- AWS cloud architecture
- Query optimization and schema design across MySQL, MariaDB and PostgreSQL
- Automated testing, code review and CI/CD as part of how I ship

Ask me about PHP, Node.js/NestJS, REST API design, or relational database optimization. English: comfortable working in English-speaking environments.
